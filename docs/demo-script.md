# 2-minute demo script

Record your screen (for example Loom, OBS, or Windows Snipping Tool screen recording) on the **live URL in an incognito window**.

| Time | Show | Say |
|---|---|---|
| 0:00–0:15 | Landing page | "First-time PC buyers don't know which parts fit together or how to split a budget. PC Build Advisor builds a compatible PC from a store's own catalogue." |
| 0:15–0:45 | Enter PHP 40,000 + Gaming → **Suggest a build** | "I give a budget and use case. Watch the tool steps: it searches the catalogue per category, then runs a compatibility check." |
| 0:45–1:05 | Build panel | "Every part is a real catalogue item. The total, budget left and power estimate are calculated by code, not the AI. Green means socket, memory, size, cooling and power checks all passed." |
| 1:05–1:25 | Type "make it quieter and use an AMD graphics card" | "Follow-ups update the build, and it is re-checked every time." |
| 1:25–1:40 | Type something off-topic, e.g. "write my essay" | "It stays on task." |
| 1:40–2:00 | GitHub repo: Actions tab (green CI), tests, `/api/health` | "CI runs lint, type checks, 20+ unit tests on the rule engine and a secret scan on every push. Vercel deploys main automatically. Logs and analytics give basic monitoring." |
